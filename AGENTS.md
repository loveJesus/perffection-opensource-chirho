# Jesus Christ is Lord

## Source Guide

- Preserve the Rust/Bun architecture and Chirho identifier convention. Add the John 3:16 source header to new comment-capable files.
- Cairn owns runtime, authentication, storage and effects. Perffection owns product guests, typed documents, HTML and SCSS. Do not add an unrelated product server or auth/storage stack.
- Keep private inputs sealed and validate authority at trust boundaries. Tests must measure money, privacy, authority, recovery and bounded growth, not incidental formatting.
- Preserve lockfiles and third-party notices. Run the documented build, focused behavioral tests, formatting and strict lint before claiming a change works.
- Never commit credentials, private keys, customer state, host configuration, patent forms or personal legal documents.
- Read `docs-chirho/licensing-chirho.md` before modifying licensing or accepting external contributions. No contribution is silently assumed to permit commercial relicensing.
- Source availability does not enable public signup, providers, production money, deployments or real-user delivery. Those are separate operational decisions.
- Keep edits scoped, preserve other writers' changes, use branch `main_chirho` and remote `gh_chirho`, and report actual unexecuted or failed checks.

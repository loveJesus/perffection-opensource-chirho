# Source Boundary

This is a clean-history source distribution, not an export of the original project history. Runtime/product source, declared local dependencies, lockfiles, authored assets and synthetic tests are retained. Credentials, runtime/customer state, host runbooks, private strategy, patent files and private work records are excluded.

The inventory records original Git blobs and original/prepared SHA-256 values. Old source hashes identify provenance, not Git objects promised to exist in the new public history. The engine uses its actual current clean commit as its build identity; the product records that exact commit in CAIRN-PIN-chirho.txt.

Read the licensing guide for AGPL, the explicit guest-authoring exceptions and retained third-party notices. Existing permissive permissions are not retroactively withdrawn. Check private-data boundaries and the complete intended history before any visibility change.

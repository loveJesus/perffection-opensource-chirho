# Contributing

Discuss substantial changes before implementation. Include a focused regression test and describe the actual commands and failures. Preserve the existing architecture, Chirho names, source headers, lockfiles and third-party notices. Do not include credentials, private customer data or host-specific configuration.

This project intends AGPL distribution with a separate commercial alternative for rights the copyright holder controls. Until a suitable explicit inbound licensing agreement is adopted, external patches are not merged merely on the strength of a sign-off or the Git hosting site's default contribution terms. Do not submit third-party work you lack permission to contribute. Public issues can discuss behavior without disclosing private vulnerability details or private legal material.
